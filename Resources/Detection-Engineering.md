# Detection Engineering Resources

| Resource | Use |
|---|---|
| [Sigma documentation](https://sigmahq.io/docs/) | Generic detection rule format |
| [MITRE ATT&CK](https://attack.mitre.org/) | Behavior mapping |
| [Atomic Red Team](https://github.com/redcanaryco/atomic-red-team) | Controlled test library; review each test and prerequisites |
| [MITRE Caldera](https://caldera.mitre.org/) | Adversary emulation platform |
| [NIST SP 800-137](https://csrc.nist.gov/pubs/sp/800/137/final) | Information security continuous monitoring |

Validate detections with representative telemetry, benign baselines, and controlled test procedures.
