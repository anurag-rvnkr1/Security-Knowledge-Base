# Blue Team Resources

| Resource | Focus |
|---|---|
| [CISA Cybersecurity Performance Goals](https://www.cisa.gov/cross-sector-cybersecurity-performance-goals) | Baseline defensive practices |
| [NIST CSF](https://www.nist.gov/cyberframework) | Risk outcomes and program improvement |
| [MITRE ATT&CK](https://attack.mitre.org/) | Adversary behavior and defensive mapping |
| [CIS Controls](https://www.cisecurity.org/controls) | Prioritized safeguards |
| [Microsoft Security documentation](https://learn.microsoft.com/security/) | Defender and security operations guidance |
| [Wazuh documentation](https://documentation.wazuh.com/current/) | Open-source security monitoring platform |

Select controls based on risk, environment, and operational capability.
