# Application Security Resources

| Resource | Use |
|---|---|
| [OWASP ASVS](https://owasp.org/www-project-application-security-verification-standard/) | Verifiable application security requirements |
| [OWASP WSTG](https://owasp.org/www-project-web-security-testing-guide/) | Web assessment methodology |
| [OWASP API Security](https://owasp.org/www-project-api-security/) | API risk awareness |
| [OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org/) | Implementation guidance |
| [NIST SSDF (SP 800-218)](https://csrc.nist.gov/pubs/sp/800/218/final) | Secure software development practices |
| [OpenSSF](https://openssf.org/) | Open-source software security initiatives |

Use the applicable standard release and adapt verification depth to risk.
