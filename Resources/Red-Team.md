# Red Team Resources

| Resource | Focus |
|---|---|
| [MITRE ATT&CK](https://attack.mitre.org/) | Adversary behavior reference |
| [OWASP Web Security Testing Guide](https://owasp.org/www-project-web-security-testing-guide/) | Authorized web testing methodology |
| [NIST SP 800-115](https://csrc.nist.gov/pubs/sp/800/115/final) | Technical security testing guidance |
| [PTES](http://www.pentest-standard.org/) | Penetration test planning and reporting framework |
| [NIST NICE Framework](https://www.nist.gov/itl/applied-cybersecurity/nice/nice-framework-resource-center) | Workforce tasks and competencies |

Operate only under written authorization, clear scope, and agreed rules of engagement.
