# RFCs and Protocol Specifications

The [RFC Editor](https://www.rfc-editor.org/) is the canonical source for RFC publication status and text. RFCs document Internet standards, best current practices, and informational material; not every RFC is a standard.

|---|---|
| [RFC 8446](https://www.rfc-editor.org/rfc/rfc8446) | TLS 1.3 |

| [RFC 9112](https://www.rfc-editor.org/rfc/rfc9112) | HTTP/1.1 |
| [RFC 1034](https://www.rfc-editor.org/rfc/rfc1034) and [RFC 1035](https://www.rfc-editor.org/rfc/rfc1035) | DNS concepts and implementation |
| [RFC 5321](https://www.rfc-editor.org/rfc/rfc5321) | SMTP |
| [RFC 6749](https://www.rfc-editor.org/rfc/rfc6749) | OAuth 2.0 authorization framework; consult current security BCPs too |
| [RFC 9116](https://www.rfc-editor.org/rfc/rfc9116) | security.txt |

Always check for updates, errata, and successor specifications.
