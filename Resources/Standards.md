# Standards and Frameworks

| Standard / framework | Publisher | Use |
|---|---|---|
| [NIST Cybersecurity Framework](https://www.nist.gov/cyberframework) | NIST | Cybersecurity risk management outcomes |
| [NIST SP 800 series](https://csrc.nist.gov/publications/sp800) | NIST | Detailed security and privacy guidance |
| [CIS Critical Security Controls](https://www.cisecurity.org/controls) | CIS | Prioritized safeguards |
| [CIS Benchmarks](https://www.cisecurity.org/cis-benchmarks) | CIS | Secure configuration recommendations |
| [ISO/IEC 27001](https://www.iso.org/isoiec-27001-information-security.html) | ISO | Information security management systems |
| [PCI DSS](https://www.pcisecuritystandards.org/) | PCI SSC | Payment card data security requirements |
| [MITRE ATT&CK](https://attack.mitre.org/) | MITRE | Adversary behavior reference, not a compliance standard |

Check the applicable edition, licensing, and regulatory context.
