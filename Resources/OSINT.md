# OSINT Resources

| Resource | Use |
|---|---|
| [ICANN Lookup](https://lookup.icann.org/) | Registration data where available |
| [Certificate Transparency](https://certificate.transparency.dev/) | Public certificate ecosystem information |
| [RIPEstat](https://stat.ripe.net/) | Internet number resource and routing context |
| [IANA](https://www.iana.org/) | Protocol registries and assignments |
| [CISA](https://www.cisa.gov/) | Public advisories and infrastructure context |

Publicly accessible does not mean unrestricted: respect privacy, terms, and laws; corroborate sources and avoid exposing personal information.
