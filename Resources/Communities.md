# Security Communities

| Community | Focus |
|---|---|
| [OWASP local chapters](https://owasp.org/chapters/) | Application security |
| [FIRST](https://www.first.org/members/teams/) | Incident response teams and coordination |
| [ISACA chapters](https://www.isaca.org/membership/local-chapter-information) | Audit, governance, risk, and security |
| [IETF groups](https://datatracker.ietf.org/wg/) | Internet protocol standards |
| [DEF CON Groups](https://defcongroups.org/) | Local security meetups |
| [CNCF communities](https://www.cncf.io/community/) | Cloud-native projects and security |

Follow community codes of conduct, protect private information, and share only material you have permission to disclose.
