# Threat Hunting Resources

| Resource | Use |
|---|---|
| [MITRE ATT&CK](https://attack.mitre.org/) | Structure behavior-based hypotheses |
| [CISA advisories](https://www.cisa.gov/news-events/cybersecurity-advisories) | Threat context and defensive actions |
| [SigmaHQ rules](https://github.com/SigmaHQ/sigma) | Community detection content; validate before use |
| [Zeek documentation](https://docs.zeek.org/) | Network telemetry |
| [Microsoft Sentinel KQL](https://learn.microsoft.com/azure/data-explorer/kusto/query/) | Query language reference |

Hunts should state data coverage, time range, assumptions, and limitations.
