# Digital Forensics and Incident Response

| Resource | Focus |
|---|---|
| [NIST SP 800-61 Rev. 2](https://csrc.nist.gov/pubs/sp/800/61/r2/final) | Computer security incident handling; check NIST for current revision |
| [NIST SP 800-86](https://csrc.nist.gov/pubs/sp/800/86/final) | Integrating forensics into incident response |
| [CISA incident response resources](https://www.cisa.gov/topics/cyber-threats-and-advisories/incident-response) | Operational guidance |
| [The Sleuth Kit](https://www.sleuthkit.org/) | Digital investigation tools |
| [Volatility Foundation](https://volatilityfoundation.org/) | Memory forensics framework |
| [Autopsy](https://www.autopsy.com/) | Digital forensics platform |

Follow organizational evidence and privacy procedures; tools do not replace sound acquisition practice.
