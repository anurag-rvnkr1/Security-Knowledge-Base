# Security Organizations

| Organization | Role |
|---|---|
| [NIST](https://www.nist.gov/cybersecurity) | Measurement, standards, and guidance |
| [CISA](https://www.cisa.gov/) | U.S. national cyber defense and resilience guidance |
| [MITRE](https://www.mitre.org/) | Federally funded research and knowledge bases |
| [OWASP](https://owasp.org/) | Open application security projects |
| [CIS](https://www.cisecurity.org/) | Security controls and benchmarks |
| [FIRST](https://www.first.org/) | Incident response and security team coordination |
| [IETF](https://www.ietf.org/) | Internet standards development |
| [ISACA](https://www.isaca.org/) | IT governance, audit, risk, and security community |
