# Practice Platforms

Use each platform according to its terms and only within explicitly provided challenge scope.

| Platform | Use |
|---|---|
| [picoCTF](https://picoctf.org/) | Beginner-friendly CTF learning |
| [OverTheWire](https://overthewire.org/wargames/) | Command-line and security wargames |
| [PortSwigger Web Security Academy](https://portswigger.net/web-security) | Free web security training labs |
| [TryHackMe](https://tryhackme.com/) | Guided cybersecurity rooms |
| [Hack The Box](https://www.hackthebox.com/) | Authorized labs and CTFs |
| [CyberDefenders](https://cyberdefenders.org/) | Blue-team investigation challenges |
| [Immersive Labs](https://www.immersivelabs.com/) | Cyber skills exercises; access may require subscription |

Check rules and platform authorization before interacting with any target.
