# Research Papers

Use peer-reviewed venues and primary research. Read methodology, limitations, and publication date before applying findings.

| Source | Description |
|---|---|
| [USENIX Security Symposium](https://www.usenix.org/conferences/byname/108) | Peer-reviewed systems security research |
| [IEEE Symposium on Security and Privacy](https://www.ieee-security.org/) | Security and privacy research |
| [ACM CCS](https://www.sigsac.org/ccs.html) | Computer and communications security research |
| [NDSS Symposium](https://www.ndss-symposium.org/) | Network and distributed systems security |
| [arXiv Computer Security](https://arxiv.org/archive/cs.CR) | Preprints; not all submissions are peer reviewed |
| [NIST publications](https://csrc.nist.gov/publications) | Applied security and standards research |

Respect publisher licenses and cite the original work rather than redistributing copyrighted papers.
