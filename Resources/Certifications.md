# Certifications

Certification programs change; verify current objectives, eligibility, exam versions, and fees at the issuing organization.

| Issuer | Program examples | Focus |
|---|---|---|
| [CompTIA](https://www.comptia.org/certifications) | Security+, CySA+, PenTest+ | Vendor-neutral foundations and operations |
| [ISC2](https://www.isc2.org/certifications) | CC, SSCP, CISSP | Security practice and governance |
| [ISACA](https://www.isaca.org/credentialing) | CISA, CISM, CRISC | Audit, management, and risk |
| [GIAC](https://www.giac.org/certifications/) | Role-focused certifications | Technical security domains |
| [Microsoft Credentials](https://learn.microsoft.com/credentials/) | Security and cloud credentials | Microsoft platforms |
| [AWS Certification](https://aws.amazon.com/certification/) | Security Specialty and role certifications | AWS cloud |

Certifications complement practical experience; they do not guarantee competence or employment.
