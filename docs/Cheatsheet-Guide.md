# Cheatsheet Guide

Cheatsheets are quick references, not substitutes for full guidance. Keep each page focused and link to the relevant chapter.

- Verify commands and syntax against official documentation and identify platform/version assumptions.
- Explain the purpose and meaningful side effects of commands, especially destructive or privileged actions.
- Use short tables for task, syntax, and caveat; include bounded examples.
- Include defensive and investigation use cases where relevant.
- Avoid commands that target unspecified public systems.
- Note common pitfalls, output sensitivity, and required permissions.
- Recheck external links and examples during review.
