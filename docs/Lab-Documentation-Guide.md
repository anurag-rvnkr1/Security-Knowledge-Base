# Lab Documentation Guide

Use [LAB-TEMPLATE.md](../Labs/LAB-TEMPLATE.md) for reproducible exercises. A lab should make its scope and cleanup as clear as its technical steps.

Document the objective, target environment, architecture, prerequisites, and authorization boundary. Provide setup instructions that do not depend on hidden state; state versions, resources, and expected network access.

For each procedure, explain purpose, command or action, expected result, and safe verification. Include evidence and relevant telemetry, but redact secrets and personal information. Distinguish observed facts from expected behavior.

Include detection or mitigation where relevant, known limitations, troubleshooting, and a cleanup procedure that removes created resources and test data. Test steps in a disposable environment before publication.
