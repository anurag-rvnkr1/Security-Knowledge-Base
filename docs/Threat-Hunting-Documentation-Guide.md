# Threat Hunting Documentation Guide

Every hunt should state a testable hypothesis, scope, time window, data sources, field assumptions, and query rationale. Explain expected and observed results, baseline comparison, pivots, and data coverage limitations.

Record benign explanations and evidence supporting escalation. Protect personal or sensitive data. Conclude with outcome, follow-up actions, and detection or telemetry improvements. See [Threat Hunting](../Threat-Hunting/).
