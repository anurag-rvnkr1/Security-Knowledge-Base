# Responsible Use

This knowledge base supports education, defensive operations, and authorized security research.

- Security testing must be authorized by the system owner and remain within the written scope.
- CTF activities must stay within the platform's authorized challenge environment.
- Labs should use controlled, preferably isolated, systems and synthetic data.
- Do not publish credentials, secrets, access tokens, private keys, or sensitive personal information.
- Protect evidence and follow organizational privacy and retention policies.
- Report vulnerabilities through responsible disclosure and coordinated channels.
- Use security tools lawfully and comply with applicable policy, terms, and law.
- Stop testing if scope is unclear, unexpected impact occurs, or authorization expires.

Authorization is specific to systems, methods, and time; possession of a tool or public reachability is not permission.
