# Naming Conventions

Existing repository conventions take priority; the tree contains legacy variations in capitalization and numbering, so do not rename established content as part of an unrelated contribution.

- **New domain folders:** use descriptive `Title-Case-With-Hyphens` names when consistent with neighboring domains.
- **Topic files:** use descriptive names such as `Threat-Hunting.md`; numbered chapters may follow a domain's established sequence.
- **Readme files:** use the capitalization already established within the target directory.
- **Images:** use lowercase descriptive names such as `01-network-architecture.png`.
- **Diagrams:** use descriptive lowercase names such as `incident-response-flow.svg`.
- **Templates:** use clear names such as `LAB-TEMPLATE.md`.

Avoid vague names such as `notes1.md`, `final.md`, or `new.md`. Use hyphens rather than spaces in new filenames for portability.
