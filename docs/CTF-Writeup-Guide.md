# CTF Writeup Guide

Use [WRITEUP-TEMPLATE.md](../CTF-Writeups/WRITEUP-TEMPLATE.md) and follow the platform's publication rules.

Explain the challenge overview, scope, reconnaissance, enumeration, method, evidence, and lessons learned. Document why each step was selected; do not present unexplained command dumps. Include exploitation or privilege escalation only as applicable to the authorized challenge.

Provide a defensive perspective: observable behavior, possible telemetry, and mitigations. Identify tool versions and references. Mark spoilers, omit flags when restricted, and never include real credentials, tokens, victim data, or sensitive information. If a finding affects a real system, use responsible disclosure rather than publishing an actionable target-specific writeup.
