# Resource Curation Guide

Add resources that are relevant, legitimate, educational, and maintained where possible. Prefer official documentation, standards bodies, established organizations, and peer-reviewed work.

For books, courses, research, tools, standards, communities, and practice platforms, identify type, subject, and intended use. Note costs, access requirements, version scope, or preprint status when known. Confirm ownership and link directly to the source.

Exclude link spam, copied material, unsafe datasets, leaked information, and services that invite activity beyond authorization. Revisit links periodically and remove or annotate obsolete resources.
