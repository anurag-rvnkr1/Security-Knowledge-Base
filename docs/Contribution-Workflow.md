# Contribution Workflow

```text
Fork → Create branch → Add focused documentation → Validate Markdown and links
→ Review technical accuracy → Commit → Open pull request
```

1. Search the repository and open discussions to avoid duplicate material.
2. Create a focused branch and place content in the appropriate existing section.
3. Follow the [documentation guide](./Documentation-Guide.md) and [responsible-use policy](./Responsible-Use.md).
4. Verify commands, queries, versions, external references, and relative links.
5. Review the final diff for secrets, private data, accidental scope expansion, and generated artifacts.
6. Use a descriptive commit message and explain scope, validation, and limitations in the pull request.
7. Address review feedback and update references that change before merge.

Do not include unrelated refactors or commit credentials. Follow the repository's contribution instructions and maintainers' review process.
