# SIEM Quick Reference

| Workflow | Checklist |
|---|---|
| Onboard source | Confirm owner, transport, timestamps, parsing, retention, and access |
| Validate data | Check sample events, field types, timezone, and missing values |
| Investigate alert | Preserve alert context; pivot by entity and time window |
| Tune detection | Measure false positives and coverage before changing logic |
| Close case | Record evidence, conclusion, actions, and follow-up |

Queries depend on schema and platform. See [SIEM](../SIEM/) and [Detection Engineering](../Detection-Engineering/).
