# Digital Forensics Quick Reference

| Practice | Reason |
|---|---|
| Confirm authority and scope | Protects privacy and legal integrity |
| Record source, handler, time, and actions | Supports provenance and reproducibility |
| Preserve originals; analyze verified copies | Reduces accidental alteration |
| Hash acquired files where appropriate | Detects later changes; does not prove authenticity alone |
| Normalize timezone carefully | Prevents timeline errors |
| Document tools and versions | Makes findings reproducible |

Follow organizational evidence procedures. See [Digital Forensics](../Digital-Forensics/).
