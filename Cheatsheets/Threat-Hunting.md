# Threat Hunting Quick Reference

1. State a falsifiable hypothesis.
2. Identify required data sources, fields, time range, and visibility gaps.
3. Write a bounded query and compare with a baseline.
4. Pivot on entities and related events; preserve timestamps and source context.
5. Validate suspicious evidence before escalating.
6. Record benign explanations, limitations, and next steps.
7. Convert useful findings into tested detections or telemetry improvements.
