# OWASP Quick Reference

| Resource | Use |
|---|---|
| [OWASP Top 10](https://owasp.org/www-project-top-ten/) | Awareness of prevalent web application risk categories |
| [API Security Top 10](https://owasp.org/www-project-api-security/) | API-specific risk taxonomy |
| [Web Security Testing Guide](https://owasp.org/www-project-web-security-testing-guide/) | Testing methodology |
| [Application Security Verification Standard](https://owasp.org/www-project-application-security-verification-standard/) | Verifiable application security requirements |
| [Cheat Sheet Series](https://cheatsheetseries.owasp.org/) | Developer-focused implementation guidance |

Use current project releases; the Top 10 is an awareness document, not a complete testing standard. See [OWASP](../OWASP/).
