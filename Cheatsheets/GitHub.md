# GitHub Quick Reference

| Task | `gh` command |
|---|---|
| Check authentication | `gh auth status` |
| List open PRs | `gh pr list` |
| View PR checks | `gh pr checks` |
| View issue | `gh issue view NUMBER` |
| Create PR from current branch | `gh pr create` |
| View remote repo | `gh repo view OWNER/REPO` |

Review command targets before publishing. Never paste access tokens into shell history, issues, or documentation. See [GitHub CLI manual](https://cli.github.com/manual).
