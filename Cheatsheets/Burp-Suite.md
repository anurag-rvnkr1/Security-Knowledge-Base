# Burp Suite Quick Reference

Use Burp only against an application explicitly authorized for testing. Configure scope before browsing.

| Task | Practice |
|---|---|
| Define scope | Add only approved hosts under Target scope |
| Inspect traffic | Proxy HTTP history; compare request and response |
| Repeat a request | Send an in-scope item to Repeater and change one variable at a time |
| Review site map | Use Target site map for observed paths only |
| Save evidence | Remove cookies, tokens, and personal data before sharing |

Do not run intrusive scans against production without written approval and a defined test window. See [Web Security](../Web-Security/) and [API Security](../API-Security/).
