## Safe Use

Commands that inspect or change systems must be used only on systems within your authorization. Examples favor local inspection and read-only use; commands that can alter or remove data are identified with a warning.

## Responsible Use

Use security tools only on systems and data you own or are explicitly authorized to assess. Protect secrets and sensitive output.
