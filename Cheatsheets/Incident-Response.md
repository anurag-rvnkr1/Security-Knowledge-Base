# Incident Response Quick Reference

| Phase | Immediate focus |
|---|---|
| Preparation | Roles, contacts, logging, backups, authority |
| Detection and analysis | Validate signal, scope systems/accounts, preserve evidence |
| Containment | Choose proportionate, approved actions; record business impact |
| Eradication and recovery | Remove cause, restore from trusted state, monitor |
| Post-incident | Timeline, lessons, owners, and measurable follow-up |

Use the organization’s approved plan and legal/compliance escalation paths. See [Incident Response](../Incident-Response/).
